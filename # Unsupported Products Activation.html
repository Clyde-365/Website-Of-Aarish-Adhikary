Microsoft 365 Apps for Enterprise

Enterprise

This guide provides official methods for deploying and activating Microsoft 365 Apps for Enterprise in your organization.

Deployment Methods

  • Microsoft 365 Admin Center
  • Office Deployment Tool (ODT)
  • Configuration Manager
  • Intune

Activation Methods

  • User-based licensing
  • Device-based licensing
  • Shared computer activation

Deployment Guide

Enterprise

Option 1: Microsoft 365 Admin Center

  1. Sign in to Microsoft 365 Admin Center
  2. Go to "Setup" → "Apps and devices"
  3. Choose "Apps" and select Microsoft 365 Apps for Enterprise
  4. Configure installation options and deploy

Option 2: Office Deployment Tool (ODT)

  1. Download the Office Deployment Tool
  2. Create configuration XML file using Office Customization Tool
  3. Run ODT with your configuration: setup.exe /configure configuration.xml

Option 3: Configuration Manager

  1. In Configuration Manager console, go to "Software Library"
  2. Choose "Office 365 Client Management"
  3. Use the Office 365 Installer wizard
  4. Deploy to your device collections

Option 4: Microsoft Intune

  1. In Intune admin center, go to "Apps" → "All apps"
  2. Add "Microsoft 365 Apps for Windows 10 and later"
  3. Configure app suite settings
  4. Assign to groups

Activation Methods

Enterprise

User-Based Activation

  • Requires valid Microsoft 365 E3/E5 license
  • Users sign in with work account
  • Supports up to 5 devices per user
  • Automatically activates Office apps

Device-Based Activation

  • Requires Windows 10/11 Enterprise or Education
  • Device must be Azure AD joined
  • Configure in Microsoft 365 Admin Center:
    1. Settings → Org Settings
    2. Services → Device-based licensing
    3. Enable "Device-based licensing for Microsoft 365 Apps for enterprise"

Shared Computer Activation

  • For devices accessed by multiple users
  • Enable using ODT or Group Policy: <Property Name="SharedComputerLicensing" Value="1"/>
  • Users must have valid license
  • Credentials cached for offline use

Troubleshooting

Enterprise

Activation Issues

  • Run activation troubleshooter: %ProgramFiles%\Microsoft Office\Office16\SARA.exe
  • Check license status: cscript "C:\Program Files\Microsoft Office\Office16\OSPP.VBS" /dstatus
  • Reset activation state: cscript "C:\Program Files\Microsoft Office\Office16\OSPP.VBS" /rearm

Common Solutions

  • Verify internet connectivity
  • Check license assignment in Admin Center
  • Confirm Azure AD device registration
  • Clear Office credentials:
    1. Settings → Accounts → Access work or school
    2. Select account → Disconnect
    3. Restart Office apps and sign in again

Remote Desktop Services / Client Access Licenses (RDS CALs)

Enterprise

Installation
Remote Desktop Services Installation Guide

Activation
There is no validation during the activation of RDS licenses.

  1. Open "Remote Desktop Licensing Manager"
  2. Right-click the server and click "Activate Server"
  3. Select the connection method of choice and click next (default is fine)
  4. Fill the first company information with garbage and click next
  5. Leave the next page blank and click next
  6. The wizard should complete and say "The license server has been successfully activated"
  7. Keep "Start Install Licenses Wizard" checked and click next until it asks you to select a "License program"
  8. Change the License Program to "Service Provider License Agreement" in the dropdown and click next
  9. Set the agreement number to 1234567 and click next
  10. Fill out the next page with your chosen values and click next
  11. The license wizard should report "The requested licenses have been successfully installed"
